# Miniature Smart Greenhouse

[`English README`](../README.md)

ESP32 を用いた、小型密閉型テラリウム／温室向けの環境監視・制御システムです。  
室内環境（ペットのいる家庭を含む）において、植物の健全な生育状態を維持することを目的としています。  
市販の既製品コンポーネントと、明示的な有限状態機械（FSM）によるシンプルな制御構成を採用しています。  
安全性を重視し、起動時やエラー発生時にはすべての出力が OFF となる設計です。

## 目標

### v1.0 における現実的な機能範囲

#### 監視

- 気温
- 湿度
- 土壌温度
- 土壌湿度
- 時刻

#### 制御

- 換気ファン（PWM・多段制御）
- 植物育成用 LED（時刻制御・温度制限）
- 土壌加熱マット（PWM・ヒステリシス制御）
- ステータス LED（土壌湿度インジケータ）

#### セーフティ

- 起動時およびセンサー異常時、すべてのアクチュエータはデフォルトで OFF となる。

**現在のチューニングおよび検証対象:**

![camellia japonica var. japonica / image courtesy of Wikipedia](img/Camellia_japonica.png)

- 理想気温: 10–22 °C
- 理想湿度: 50–70 %
- 理想土壌温度: 12–20 °C
- 理想土壌湿度: 30–45 %

## ハードウェア概要

入手容易な市販コンポーネントを用いて構成しています。

### マイコン

- ESP32-C3 Super Mini

### 電源

- 12 V DC 電源
- LM2596 降圧コンバータ（12 V → 5 V）

### センサー

- DS18B20 — 土壌温度（OneWire）
- SHT31-D — 気温・湿度（I²C）
- CAP-SW-12 — 土壌湿度（ADC）
- DS1307 — リアルタイムクロック（I²C）

### アクチュエータ

- 12 V LED 育成ライト（MOSFET + PWM）
- 5 V 換気ファン ×2（MOSFET + PWM、フライバックダイオード）
- USB 土壌加熱マット（MOSFET + 温度ヒューズ）
- ステータス LED（GPIO 制御）

## ソフトウェア構成

単一ループによる状態駆動型設計。

### 高レベル処理フロー

```
センサー読み取り
   ↓
内部状態の更新
   ↓
状態に基づくアクチュエータ制御
   ↓
待機／アイドル
```

## セーフティノート

### ハードウェア

- 土壌加熱マットには、機械的安全遮断として温度ヒューズを搭載。
- ファン駆動回路には、スイッチング保護のためフライバックダイオードを使用。

### ソフトウェア

- 制御ロジックには明示的なヒステリシスを実装。
- 起動時、すべての出力はデフォルトで OFF。
- センサー読み取りエラー時は、安全側（OFF）に遷移。
- v1.0 時点では WDT（ウォッチドッグ）や自律的障害回復機構は未実装。
